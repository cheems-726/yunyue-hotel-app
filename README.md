# 云悦酒店 · 连锁酒店经营模拟教学系统

面向酒店管理课堂的多人经营模拟：学生从选址（成德绵片区）→ 选品牌（华住）→ 认领 → 筹建 → 12 周连续经营 → 最终四维评分，全程云端存档、教师实时看板。

## 线上入口

- 网页版（PWA）：https://yunyue-hotel-app.vercel.app
- 安卓 APK：见发行版 / 仓库外发安装包（versionCode 递增，可直接覆盖安装）

## 技术栈

- 前端：React 18 + Vite，移动端优先（max-width 480 单栏）
- 云端：Supabase（Auth + Postgres + RLS 多租户），东京区
- 移动端：Capacitor 7 打包 APK
- 托管：Vercel（push main 自动部署）

## 核心机制

- **18 项能力点决策**（5 类交互：选项/滑块/预算分配/排序/倒计时），全部接入结算引擎
- **结算引擎**（src/settlement.js）：客源强度 = 价格竞争力 × 口碑 × 营销 × 市场波动 × 城市客流 × 竞争；固定随机种子（全班同周同结果，公平）
- **条件触发事件系统**：12 种事件（负面：满负荷响应慢/卫生敷衍/性价比失衡/竞店开业/消防检查/停水/危机·差评发酵；正面：网红探店/会员复购/整改追加好评/会展旺季/OTA金牌）——按"经营状态条件 + 固定种子概率"触发，非纯随机
- **危机限时应对**：危机事件 30 秒倒计时选方案，跨周影响口碑
- **教学进度控制**：教师设定全班统一周，学生结算超周被拦
- **四维评分**：利润 40% / 口碑 25% / 出租率 20% / 差评处理 15%（学生端实时可查，与教师端同口径）
- **酒店称号成长**：普通旅社 → 标杆酒店（5 级）
- **数据三层保险**：云端自动存 + 本机 localStorage + 手动导出 JSON 备份

## 账号规则

- 学生：纯数字学号注册（如 20240101）
- 教师：T + 数字工号（如 T001），自动获得全班数据查看权
- 邮箱映射约定：`学号@yunyue.study`

## 本地开发

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # 产出 dist/
python build.py      # 递增版本号并打包 APK（需 Android SDK，路径见 项目进度总纲.md）
```
